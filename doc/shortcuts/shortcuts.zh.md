## 快捷键
> **注意**: 举个例子，比如这里写了`Ctrl + X` `Ctrl + S`，它的意思是先按`Ctrl + X`，然后马上按`Ctrl + S`。

* **保存**: `Ctrl + X` `Ctrl + S`.
* **退出**: `Ctrl + X` `Ctrl + C`.
* **剪切**: `Ctrl + W`.
* **复制**: `Alt + W`.
* **粘贴**: `Ctrl + Y`.
* **补全列表**: `Alt + /`.
* **自动补全**: `Ctrl + C` `Alt + L`.
* **自动修复**: `Ctrl + C` `A`.
* **向前 / 向后查找**: `Ctrl + S` / `Ctrl + R`. (`Enter`结束，`Ctrl + G`回到起点)
* **逐个替换**: `Alt + %`. (`Y`/`空格`替换，`N`跳过，`!`全部替换，`.`替换后结束，`Q`结束)
* **跳转到行**: `Alt + G` `G` (或`Alt + G` `Alt + G`).

## 终端

* `Ctrl + C` `T` `T`：打开或隐藏终端。隐藏后 Shell 继续运行。
* `Ctrl + X` `O`：在已显示的面板之间切换焦点：文件树、编辑器和终端。
* `Ctrl + C` `T` `C`：运行 Clang-tidy。
* `Alt + V` / `Ctrl + V`：向上 / 向下翻阅终端历史输出。
  也支持 `Shift + PageUp` / `Shift + PageDown`，最多保留 1000 行历史。
  这些快捷键在终端获得焦点时生效；输入时自动回到最新输出。
  程序使用备用屏幕时，这些按键仍传给程序。
* 终端获得焦点时，Ctrl-C、Ctrl-D 等按键会传给 Shell。
  使用编辑器命令前，请按 `Ctrl + X` `O` 切回编辑器。

工作区高度不少于 28 行时，终端显示在编辑器下方；否则显示在右侧。
Shell 在当前文件的目录启动；未命名文件则使用编辑器的工作目录。
Shell 退出后，隐藏并重新打开终端即可启动新会话。

## 文件树

* `Ctrl + C` `C` `T`：在左侧显示或隐藏文件树，类似 Emacs 的 Treemacs。
  也可以从 WINDOW 菜单打开。显示文件树时焦点会移到文件树上。
* `N` / `P`：下一行 / 上一行。也支持 `Down` / `Up` 和 `Ctrl + N` / `Ctrl + P`。
* `Tab`：展开或折叠选中的目录。
* `Enter`：在新标签页中打开选中的文件（已打开的文件会切换到它的标签页），
  或展开 / 折叠选中的目录。
* `U`：跳到上级目录。
* `G`：重新读取目录。
* `Q`：隐藏文件树。

文件树从当前文件所在的项目开始：即向上找到的第一个含有 `.git`、`Cargo.toml`、`CMakeLists.txt`、
`compile_commands.json` 或 `compile_flags.txt` 的目录（找不到时使用文件所在的目录）。
未命名文件则从编辑器的工作目录开始。
打开时会展开当前文件上层的目录并选中它。`.git` 目录不会显示。

## 标签页

* `Ctrl + X` `Right` / `Ctrl + X` `Left`：切换到下一个 / 上一个标签页。在最后一个标签页时，下一个是第一个。
* `Ctrl + X` `K`：关闭标签页。有未保存的修改时会先弹出对话框询问：
  `Y` / `Enter` 不保存直接关闭，`N` / `Esc` 保留标签页。

标签栏是编辑器的第一行。当前标签页会高亮显示，`●` 表示该标签页有未保存的修改。
从文件树打开的文件会在当前标签页之后新开一个标签页；如果当前是空的未命名标签页，则直接用它打开。
关闭最后一个标签页后，会留下一个空的未命名标签页。
